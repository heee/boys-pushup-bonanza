# Roadtrip

Roadtrip turns the privacy-safe location snapshot already stored on pushup sessions into four calendar leaderboards: Day, Week, Month, and Year.

## Rankings

- Neighborhood, City, and Country territory rankings use cumulative adjusted pushup counts. Planks are excluded.
- Each location detail ranks contributors by their cumulative reps in that place and timeframe.
- A territory is claimed by its first contributor. It is conquered only when another contributor strictly exceeds the current holder; ties preserve the incumbent.
- Overview lists show the top 10 and pin the device's selected territory when it falls below them. Location details show the full local leaderboard.

## Session wins

After a located pushup session, the app checks all three location tiers across all four timeframes. New claims and strict overtakes appear together on the session summary. Wins for the same territory are collapsed into one line listing each applicable timeframe and have their own conquest share action.

All ranking and conquest state is derived from existing session history. No coordinates, pins, or new server-side location data are stored.
